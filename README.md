## *Project Overview*
This is an *interactive Power BI dashboard* analyzing Uber trips for *June 2024*.  
It provides insights into *key performance indicators (KPIs)*, trip patterns, and location-based analysis.  

*Highlights:*
- Real-time Uber trip data (103,728 trips)
- KPIs: Total Bookings, Average Trip Time, Revenue, Surge Fee, etc.
- Location analysis: Frequent pickup & drop-off points
- Interactive dashboard: Slicers, filters, drill-through features

## *Project Files and Data*

### *Raw Data*
- **trip_details.xlsx** – Fact table containing trip-level data (103,728 rows, 11 columns)  
- **locations.xlsx** – Dimension table containing location info (265 rows)  

### *Power BI File*
- **Uber_Analysis.pbix** – Main working Power BI dashboard file

## *How to Use*
1. Download the repository files.  
2. Open **Uber_Analysis.pbix** in *Power BI Desktop*.  
3. Load the datasets **trip_details.xlsx** and **locations.xlsx** if not embedded.  
4. Explore *slicers, filters, drill-throughs, and dynamic KPIs*.
