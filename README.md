# 🚖 Power BI Uber Data Analysis Dashboard

## 📌 Project Overview
An interactive *Power BI dashboard* analyzing *Uber trip data* for *June 2024 (New York City)*.  
It highlights business insights, trip trends, and key performance metrics.

---

## 🎯 Objective
To visualize Uber’s trip performance through:
- Total Bookings  
- Total & Average Revenue  
- Trip Distance and Duration  
- Vehicle Type and Payment Insights  

---

## 📂 Files in Repository
- Uber_Analysis.pbix → Power BI working file  
- Trip_Details.xlsx → Main dataset (103,728 rows)  
- Locations.xlsx → Location reference table  
  
---

## 🧠 Data Model
- *Schema:* Star Schema  
- *Fact Table:* Trip Details  
- *Dimension Tables:* Locations, Calendar  
- Includes *active & inactive relationships* (pickup/drop IDs)

---

## 📊 Dashboard Highlights
- 6 Key KPIs for overall performance  
- Time-based, location-based, and vehicle-based analysis  
- Drill-through, bookmarks, and slicers for interactivity  
- Conditional formatting for clear visual insights  

---

## ⚙ How to Use
1. Download all repository files  
2. Open Uber_Analysis.pbix in *Power BI Desktop*  
3. Load Excel data if prompted  
4. Explore and interact with filters & visuals  

---

## 🧾 Key Insights
- Evening hours show the highest bookings  
- Manhattan and Brooklyn have maximum trips  
- SUV and Sedan are top-performing vehicle types  

---
